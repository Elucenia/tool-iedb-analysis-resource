# IEDB SMM: ارتباط الببتيد بجزيئات MHC I

SMM 1.0، MHC I، ببتيدات بطول 9 أحماض أمينية؛ الأليلان HLA-A*01:01 وHLA-A*02:01. تسلسل من 9 إلى 200 حمض أميني قياسي. IC50 المتوقعة بوحدة nM والرتبة المئينية ليستا قياسات تجريبية أو إثباتًا للمناعية.

## النطاق

تحليل حاسوبي لأغراض البحث. لا يحدد التشخيص أو الإمراضية أو الفعالية أو العلاج. تحقّق من المجموعة والمصدر والإصدار والنطاق قبل التفسير.

تم تنفيذ الواجهة وعقود الطلب والاستجابة داخل ELUCENIA. يعتمد التحليل على توفر الخدمة المسؤولة. لم تكتمل المراجعة السريرية المستقلة ولا المراجعة اللغوية المهنية.

## الاستعلام

- تسلسل الأحماض الأمينية
- أليل HLA
- أؤكد أنني سأرسل بيانات بحثية عامة أو اصطناعية فقط، دون بيانات مرضى أو معلومات سرية.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "properties": {
    "sequence": {
      "type": "string",
      "minLength": 9,
      "maxLength": 200,
      "pattern": "^[ACDEFGHIKLMNPQRSTVWY]+$"
    },
    "allele": {
      "enum": [
        "HLA-A*01:01",
        "HLA-A*02:01"
      ]
    },
    "publicResearchData": {
      "const": true,
      "description": "Only public or synthetic research inputs; no patient/confidential data."
    }
  },
  "required": [
    "sequence",
    "allele",
    "publicResearchData"
  ],
  "additionalProperties": false
}
```

تُحفظ الأسماء الرسمية للمصطلحات والمعرّفات العلمية بلغة المصدر؛ تسميات الواجهة مترجمة.

## النتائج

- أليل HLA
- الببتيد
- البداية
- النهاية
- IC50 المتوقعة (nM)
- الرتبة المئينية

يحفظ التصدير المصادر والنسب والإصدارات والحدود. تحتفظ البيانات الأصلية بترخيصها.

## الإصدار

`SMM 1.0 · MHC I · API 2.15`

يُطلب SMM 1.0 صراحةً. تحدد الوثائق واجهة API 2.15؛ ولا تكشف الاستجابة بصمة التجزئة للنموذج الثنائي قيد التشغيل.

## المصادر

يتبع الوصول إلى واجهة IEDB إرشادات الاستخدام؛ لا يُدعم سوى SMM 1.0 وأليلين موثقين. لا تُعاد مشاركة ملفات DTU الثنائية. لا يثبت توقع الارتباط المناعية أو الفعالية.

- [https://tools.iedb.org/main/tools-api/](https://tools.iedb.org/main/tools-api/)
- [https://tools.iedb.org/main/usage-guidelines/](https://tools.iedb.org/main/usage-guidelines/)
- [https://tools.iedb.org/analyze/pdf/peters_2005_bmc_bioinformatics.pdf](https://tools.iedb.org/analyze/pdf/peters_2005_bmc_bioinformatics.pdf)

## حدود الانتظار

الحد الزمني لكل طلب إلى هذا المزوّد هو 90 ثانية. الحد الزمني لسير العمل الكامل هو 120 ثانية، وتنتظر الواجهة 125 ثانية كحد أقصى. تتشارك الطلبات الوقت المتبقي لسير العمل. لا توجد إعادة محاولة تلقائية. إذا لم يستجب المزوّد في الوقت المحدد، ينتهي التحليل بخطأ صريح؛ ولا تُقدَّر أي نتيجة ولا تُستبدل.
